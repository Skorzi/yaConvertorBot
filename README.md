# Бот для скачивания треков с Яндекс Музыки
- Нельзя было скачивать музыку без яндекс плюс, поэтому сделал такое решение
  - Бот подключается к апи яндекс музыки и по URL скачивает на сервер песню, пересылает пользователю и удаляет с сервера
  - **/test** - Проверить активен ли бот
  - **/url** - Основная команда
